## Project Overview
This project focuses on simulating and optimizing handovers between Low Earth Orbit (LEO) satellites using Python.

## Current Features
- Sample satellite signal quality comparison
- Best satellite selection based on signal strength
- Basic time-step handover simulation

## Technologies Used
- Python
- Skyfield
- SGP4
- NumPy
- Pandas
- Matplotlib
- SciPy
- NetworkX

## Planned Improvements
- Satellite visibility modelling
- Realistic satellite orbital positions using TLE data
- Handover optimization algorithm
- Performance evaluation and graphs

## Project Status
Currently under development.
